## 🧭 What this is

AlterLab-FC-Skills is a set of 72 Claude AI skills for students and teams in communication fields. It helps with PR, advertising, cinema, new media, GenAI production, visual communication, and research work.

Use it to guide Claude through common tasks like writing, planning, reviewing, organizing ideas, and shaping media content with a clear structure.

## 🪟 Install on Windows

1. Open the downloaded file location in File Explorer.
2. If the file is a ZIP archive, right-click it and choose Extract All.
3. Pick a folder that is easy to find, such as Downloads or Desktop.
4. Open the extracted folder.
5. If you see an installer or startup file, double-click it.
6. If Windows asks for permission, choose Yes.

If the release uses skill folders for Claude, keep the folder structure the same after extraction. Many skill packs depend on the files staying in the right place.

## 🧠 How to use the skills

Once the files are in place, open Claude or Claude Code and point it to the skill set if needed.

A simple way to use the skills:
1. Open your Claude tool.
2. Start a new chat or task.
3. Ask for help in plain language.
4. Mention the kind of work you want done.

Example prompts:
- Write a PR plan for a student event
- Create a short ad concept for a class project
- Analyze a film scene for visual style
- Draft a social media post set for a campaign
- Build a research outline for a communication study
- Turn rough notes into a clean presentation script

The skills are meant to help Claude respond with better structure, cleaner output, and work that fits media and communication tasks.
